# Sorting Techniques

This repository contains implementations of fundamental sorting algorithms using Java. It is designed to help students understand how different sorting techniques work and how their performance varies with different input sizes and arrangements.

The repository includes **Bubble Sort** and can be extended with other popular sorting algorithms such as Selection Sort, Insertion Sort, Merge Sort, and Quick Sort.

## Objectives
- Understand the working principles of sorting algorithms.
- Learn how elements are compared and rearranged into sorted order.
- Analyze time and space complexity.
- Practice implementing algorithms using Java.
- Strengthen problem-solving skills for coding interviews and competitive programming.

## Technologies Used
- **Programming Language:** Java
- **Concepts:** Arrays, loops, comparisons, swapping, and algorithm complexity.

## Getting Started
1. Clone this repository.
2. Open the Java source files in your preferred IDE.
3. Compile and run the desired program.

This repository serves as a learning resource for mastering sorting algorithms and improving programming fundamentals.
